# FREE FIRE

Site acadêmico sobre a história, evolução e modos de jogo do Free Fire, desenvolvido por José Luis para a disciplina de Desenvolvimento Front-End. O projeto foi desenvolvido utilizando HTML5, sem CSS e sem JavaScript.

## Sobre o projeto

O site reúne informações sobre a origem do Free Fire, sua evolução ao longo dos anos, diferentes modos de jogo e um formulário de cadastro de jogador.

O projeto foi desenvolvido para colocar em prática os conceitos de HTML5 estudados durante a unidade, utilizando elementos semânticos, tabelas, imagens, áudio, vídeo, formulários e outros recursos da linguagem.

Desenvolvido em HTML5, com elementos semânticos, links, imagens, áudio, vídeo, tabela e campos de formulário. Sem CSS e sem JavaScript.

## Estrutura

    html/       — Páginas do projeto
    img/        — Imagens utilizadas no site
    audio/      — Arquivos de áudio
    video/      — Arquivos de vídeo
    README.md   — Documentação do projeto

## Pré-requisitos

- Navegador atualizado (Chrome, Firefox, Edge ou Safari)
- Visual Studio Code, de preferência com a extensão Live Server (opcional)
- Git, para clonar o repositório (opcional)

## Como abrir

    git clone URL_DO_SEU_REPOSITORIO
    cd NOME_DA_PASTA

Depois, abra o arquivo `html/index.html` no navegador ou clique em **Go Live** no VS Code.

Mantenha as pastas `html`, `img`, `audio` e `video` juntas na estrutura do projeto para que os caminhos dos arquivos funcionem corretamente.

## Como usar

- Use o menu presente em todas as páginas para navegar pelo projeto.
- Na página inicial, conheça a origem e a história do Free Fire.
- Na página de evolução, veja informações sobre o Free Fire e o Free Fire MAX.
- Na página de modos de jogo, conheça o Battle Royale e o Contra Squad.
- Na página de cadastro, preencha o formulário com as informações solicitadas.
- O formulário é apenas para fins acadêmicos e os dados não são enviados ou armazenados em um servidor.
